# File and Directory Operations Commands

## ls commands : for List files and directories.

- l: Long format listing.
- a: Include hidden files hidden ones
- h: Human-readable file sizes.
  •
  ls -ldisplays files and directories with detailed information.
  •
  ls -ashows all files and directories, including
  •
  ls -lhdisplays file sizes in a human-readable format.
